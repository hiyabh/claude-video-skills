התקנה בלחיצת הדבקה

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את ערכת סקילי הווידאו "בין קודש לקלוד".
1. זהה את מערכת ההפעלה שלי ואת הנתיב ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור את התיקייה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-video-skills/claude-video-skills.tar.gz
3. חלץ ממנה את כל תיקיות הסקילים אל ~/.claude/skills/ — אל תדרוס סקיל קיים בלי לשאול אותי.
4. אמת שכל 27 הסקילים הותקנו והצג לי רשימה מקובצת (יצירה / אנימציה / הורדה).
5. בדוק אילו תלויות מותקנות אצלי (Node 22+, FFmpeg, Python 3.9+) ותגיד לי מה חסר ואיך להתקין — אל תתקין תלויות כבדות לבד.

מה אפשר לייצר

  • epic-video-studio — סרטון "וואו" מורכב (HyperFrames + Manim + Lottie)
  • hyperframes + cli/media/registry — מנוע הקומפוזיציה: טקסט קינטי, כתוביות, קריינות, מעברים, רינדור
  • event-recap-video — סרטון סיכום אירוע מתמונות וקליפים
  • kids-song-video — קליפ שיר מצויר ומושר לילד
  • blessing-video-weaver — שזירת קליפי ברכה מכל המשפחה לסרטון אחד
  • dvar-torah-animation — דבר תורה מונפש 9:16 עם כתוביות מנוקדות
  • face-track-reframe — חיתוך ליחס אחר עם מעקב פנים
  • website-to-hyperframes — הפיכת אתר לסרטון

+ מנועי אנימציה: manim, lottie, remotion, gsap, anime.js, three.js, framer-motion, css, waapi · והורדת חומרי גלם: universal-downloader, browser-album-downloader

מה צריך שיהיה מותקן

  • Node.js 22+ — מנוע HyperFrames
  • FFmpeg — עריכה/רינדור וידאו ואודיו
  • Python 3.9+ — סקריפטים (Manim, event-recap, blessing, face-track)
  • GOOGLE_API_KEY (משתנה סביבה) — רק לסקילים שמייצרים תמונות/וידאו ב-AI

Claude Code יבדוק מה חסר ויסביר איך להתקין כשתריצו את הבלוק למעלה.
